# EMBERBOUND EXPEDITION キャラクター一覧

作成日：2026年10月25日  
対象：`incremental_rpg_opus` の現行実装

ゲームの機能を維持して、キャラクターを別のプログラムや素材で作り直すための一覧。名前、現在の外見、ゲーム内で担う役割を整理する。対象は **味方4種と敵40種の計44種**。召喚専用の敵と、転生後の最終戦に登場する影の4人も含む。

外見欄は現在のスプライトと描画定義に基づく。新しいデザイン案ではなく、置き換え前の仕様として扱う。年齢・身長など、実装に設定のないプロフィールは補っていない。

## 必要なキャラクター数

| 区分 | 種類数 | 内訳 |
|---|---:|---|
| 味方ヒーロー | 4 | Guardian、Ranger、Arcanist、Oracle |
| 通常敵 | 25 | 道中の24種と、召喚専用のCinder Sapling 1種 |
| エリート敵 | 6 | 各エリアに1種 |
| 単体のエリアボス | 5 | 第1〜第5エリアのボス |
| 最終戦の影のヒーロー | 4 | 第6エリアで同時に戦うボス4種 |
| **合計** | **44** | 同じ種類の複数出現や装備差分は、種類数に重複計上しない |

通常敵・エリート・ボスの分類はゲームデータに準拠する。影の4人もデータ上はボスであり、ボス全体では9種となる。`The Ember Heart` はエリア名、`The Hollow Emberbound` は影の4人の総称で、いずれも追加の単独キャラクターではない。

現在の野営地・タイトル画面も味方4人を再利用しており、店員や案内人などの独立したNPCはない。ランタン、焚き火、背景、飛び道具や魔法の演出は、キャラクター数には含めない。

### 最終ボス 影のヒーロー

4人の総称は **The Hollow Emberbound**。味方4人と対応する姿で同時に出現する。現在の描画は味方の形状と動作を再利用し、**濃紫の配色、橙色の亀裂・装飾、桃色系の発光、左右反転、1.5倍の拡大**で差別化している。

|---|---|---|---|
| **Shadow Guardian** `shadow_guardian` | ボス・大型 | Guardianと対応する兜、剣、大盾の影。濃紫の鎧と橙色の盾の縁・紋章・兜飾りを持つ。 | 敵パーティの盾役。行動できる間、他の影の被ダメージを50%軽減する。Shadow Bashで前衛を攻撃してスタンさせる。 |
| **Shadow Ranger** `shadow_ranger` | ボス・大型 | Rangerと対応するフード、軽装、大弓の影。紫の衣装、橙色のスカーフと矢、桃色に光る目が特徴。 | HPの低い味方を狙う高速射手。Deathmark Shotで弱った味方を仕留めにくる。 |
| **Shadow Arcanist** `shadow_arcanist` | ボス・大型 | Arcanistと対応する尖り帽子、ローブ、杖の影。紫黒の衣装に橙色の線が入り、杖先が桃色に発光する。 | 敵パーティの全体魔法攻撃役。Dark Meteorという全体攻撃を詠唱し、溜め中に中断できる。 |

影が1人倒れるたびに残りの影の攻撃速度が上がり、4人全員の撃破がクリア条件となる。制作時も、味方と影の対応関係が一目で分かる形を残すと、この最終戦の意味が伝わりやすい。

## キャラクターごとに必要な見た目の差分

### 味方の装備成長

4人それぞれに6段階の装備外見がある。**味方の基本外見は4種×6段階で24パターン**。形状を共用し、配色・装飾・発光の差分で表現しているため、24人の別キャラクターではない。

| 段階 | レベル | 現在の見た目の変化 |
|---|---|---|
| Tier 0 | 1〜9 | 使い込んだ青銅・革・木を中心とした初期装備。布は各職業の基本色。 |
| Tier 1 | 10〜24 | 鋼色の装備。Guardianは銀色の鎧と青い盾になり、他の職業も服や武器の色が鮮明になる。 |
| Tier 2 | 25〜49 | 金色の武器・縁取り・装飾が加わる。職業ごとの布の基本色は保たれる。 |
| Tier 3 | 50〜74 | 青銀色の装備や水色の発光。ルーン・宝石などの光る部分が加わる。 |
| Tier 4 | 75〜99 | 深紅の装備・赤いマント類・暖色の発光。Guardianは赤い鎧になるが、全員が一様に赤くなるわけではない。 |
| Tier 5 | 100以上 | 白金色の装備と明るい布色。輪郭の外側に輝くオーラが加わる。 |

敵40種には、このレベル連動の6段階の装備差分はない。装備段階を含めた外見パターンの目安は **味方24＋敵40＝64パターン**で、動作フレームや状態異常の重ね描きは別に考える。

### 動作と使用画面

| 対象 | 必要な表現 | 現行実装での扱い |
|---|---|---|
| 全キャラクター | 待機、移動、通常攻撃、詠唱・スキル、被弾、戦闘不能の6状態 | キャラクターごとに専用の絵がある状態と、待機絵の変形・移動で作る状態がある。6状態すべてに独立した原画があるわけではない。 |
| 味方4人 | 剣の斬撃・盾打ち、弓の射撃・上空射撃、杖での攻撃・詠唱、回復・結界 | 武器と動作が役割を伝える。強化後の装備でも同じ動作に対応する。 |
| 味方4人 | 野営地、パーティ画面、加入通知、タイトル画面での表示 | 戦闘用スプライトを再利用する。野営地ではRangerとArcanistの下半身を隠し、座っているように見せる。独立したNPCや立ち絵の追加は不要。 |
| 影の4人 | 味方に対応する動作と敵向きの表示 | 現状は味方の形状・動作を流用する。味方を作り直す場合、影もセットで扱う。 |
| 召喚される敵 | 出現時の表示 | Cinder Sapling、Tideling、Crystal Mite、Frost Hound、Voidspawn。既存の同名キャラクターを再利用する。 |
| Cinder Phoenix | 撃破後の復活 | 同じキャラクターが一度復活する。復活後専用の別種は不要。 |
| Coilscale Matriarch | 潜航と浮上 | 姿が隠れる時間と復帰を表現し、通常の被弾や死亡と区別する。 |
| 各ボス | 溜め攻撃、段階移行、加速・激化 | 主に戦闘状態やエフェクトで表現する。段階ごとに別キャラクターが定義されているわけではない。 |

背景や画風を変更する場合も、戦闘中の **中断可能な溜め攻撃、原則中断不可の大技、Mark、装甲・シールド、Barrier、Burn、Doom、Chill、凍結、スタン** は識別できる表示が必要になる。現在の中断可否は主にオレンジ／紫のゲージで示され、敵本体の色や魔法の見た目の色とは別に決まる。
