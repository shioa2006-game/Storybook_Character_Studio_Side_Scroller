# 横向きキャラクター制作ガイド

横スクロール用の右向き (R)・左向き (L) でキャラクターを仕上げるためのコツ・落とし穴・確認方法です。灰燼の衛士 ([warrior](../characters/warrior/character.js)) を横向きに調整したときに確かめた内容をまとめています。

描き方の基本 (座標系・顔や髪・装備・描画順・コマ割り) は [CHARACTER_GUIDE.md](CHARACTER_GUIDE.md)、登録と確認範囲は [STUDIO_GUIDE.md](STUDIO_GUIDE.md)、横スクロール化の計画は [SIDE_SCROLLER_PLAN.md](SIDE_SCROLLER_PLAN.md) を参照してください。

## 1. 横向きの見え方の仕組み

### 2つの角度

| 部位 | 座標 | 見る角度 | 理由 |
|---|---|---|---|
| 脚・足運び | `W`・`footProj` | 真横から手前へ `SIDE_VIEW_ANGLE` = 25° | 足を画面の横方向に動かし、地面の上で滑らせない |
| 上半身・腕・装備 | `U` / `UY` | さらに `SIDE_CHEST_TURN` = 20° カメラ側へひねって 45° | 胴の板を、絵を描いた幅 (斜め 45° から見た幅) で見せる |
| 頭 | 2Dの絵 (`rf.sx` で反転) | 向きによらない | 顔の見える絵を1種類だけ描く |

ひねりの量は `rf.turn` で、右向きは正、左向きは負です。視点を真横 (0°) にすると顔の正面が見えなくなるので、手前へ 25° 傾けています (頭の絵は顔の見える1種類だけ)。

胴・ベルト・腰当てなどは、前後の厚みのない「板」として描いています。板の見える幅は角度で変わります。

| 角度 | 板の見える幅 |
|---|---|
| 絵を描いた角度 (45°) | 約71% |
| 横向きの脚の角度 (25°) | 約42% (細い板に見える) |
| 上半身のひねり後 (45°) | 約71% |

### 左右反転しない: 奥側の手と手前側の手

持ち手を保つため、左右反転 (`mirror`) は使わず投影で描きます。そのため、同じ手でも向きによって奥側・手前側が入れ替わります。

| 向き | 左手 (`b > 0`) | 右手 (`b < 0`) |
|---|---|---|
| 右向き R | 奥側 | 手前側 |
| 左向き L | 手前側 | 奥側 |

上半身の座標 (a = 前、b = 左) が画面のどこに出るかの目安は、次のとおりです (ひねり後の 45°、`yaw` = 0 のとき)。

- 画面の横: `x ≒ s × a × 0.71 + b × 0.71` (右向き s = +1、左向き s = −1)
- 画面の縦: `y ≒ −z`

体の左 (`b`) は、右向き・左向きのどちらでも画面の右側へずれます。そのため同じ座標でも、右向きでは前寄り、左向きでは後ろ寄りに見えます。**左右で同じ見え方にしたい部分は、向きごとに数値を調整する必要があります** (戦士の構え `SIDE_SWORD_READY`)。

### 向きごとの処理の書き方

- 右向き・左向きで違う補正は `if(direction==='L') { … }` のように書き、奥・手前で決まるものか (上の表)、絵の見え方で決めたものかをコメントに残します (剣士の盾の重なり順、魔法使いの杖、弓使い・骸骨弓兵の弓の腕は「左向きは手前」で決まる補正)。構えなど左右で値の違う定数は `SIDE_` で始め、`{ R: …, L: … }` の形にします (戦士の `SIDE_SWORD_READY`)。
- 以前は斜め4方向 (NW / NE / SW / SE) の絵と同じコードで描き分けていましたが、横スクロール化の段階5で4方向のコードを消しました。整理の前後で左右の絵が1本の線も変わっていないことは、`tests/node/side-drawings.test.mjs` (全キャラクターの左右の描画の指紋) で確かめています。
- **独自の投影を持つキャラクター**: `bodyToWorld(rf.dir, a, b)` や独自の投影関数 (弓使いの `UG` など) へ上半身の点を渡すときは、`chestToLegs(rf.turn, a, b)` でひねりを戻してから渡します。忘れると、横向きだけ手と装備がずれます (上半身のひねりを入れたとき、弓使い・骸骨弓兵の弓が手から 5〜10px 離れていた)。骸骨の番兵のように独自のフレームを作る場合は、上半身用の投影 (`JU` / `WU`) を用意します。

## 2. よくある問題と直し方

### 2.1 体が薄く見える

- **症状**: 胴が細い板になり、大きな頭の下で「ぺらぺら」に見える。
- **原因**: 脚の角度 (25°) のまま胴を描いている。
- **直し方**: 共通リグが上半身を自動でひねります。上半身を `U` / `UY` で描けば効きます。独自のフレームで上半身を描くキャラクターには効かないので、上半身用の投影を用意します (骸骨の番兵は `skeletonFrame` に `JU` / `WU` を足し、肋骨・頭蓋骨・腕・盾をそれで描くようにした。骨盤と脚は進行方向のまま)。

### 2.2 攻撃中のひねりでさらに薄くなる

- **症状**: 振りかぶり・振り下ろしの一方で、胴が真横へ回って細くなる。
- **原因**: 攻撃のひねり (`yaw`) が、カメラから離れる向きに回る区間がある (戦士では左向きの振り下ろしと右向きの振りかぶり)。
- **直し方**: 横向きでは、カメラから離れる側のひねりだけを弱めます。戦士は `SIDE_TWIST_AWAY = 0.3` 倍。右向きは `yaw < 0`、左向きは `yaw > 0` が離れる側です。

### 2.3 振り下ろしが短く見える

- **症状**: 横へ振ったはずの剣が手前を向き、横方向の届きが短い。剣の軌跡も盾に隠れる。
- **原因**: 胸がカメラを向いた分、胸の前へ振る武器も手前を向く。
- **直し方**: 武器の**向き**を `travelDir(rf, 向き, k)` で進行方向へ戻します (共通リグ。`rf.turn + rf.yaw` の k 倍だけ逆に回す)。手の位置は動かさないので、腕が伸びすぎません。剣士・王・魔王・ゴブリン・骸骨は攻撃中ずっと、魔法使い・暗黒魔法使いは杖を前へ向ける詠唱の間だけ戻しています。戦士は同じ回転を `back` として振り下ろしの間だけ書いています。
- **注意**: この回転は、武器の前側をカメラから遠い側 (右向きなら体の左、左向きなら体の右) へ寄せます。武器が体の外側へ開く向きなら安全ですが、体の中心へ寄る向き (右向きで右手の武器・左向きで左手の武器) では、刃が頭や胴を横切ることがあります。骸骨の番兵 (右向き・右手) は頭上を通る間だけ回転を止め、魔法使い (右向き・左手の杖) は回転させると杖の石突きが胴に入ったので、左向きだけに使っています。回転を入れたら必ず自動検査を通します。

### 2.4 装備の面の向きがずれる

- **症状**: 盾の面が胸と違う方向を向く。
- **原因**: `bodyToWorld(rf.dir, a, b)` は脚の向きで計算する。
- **直し方**: 上半身の向きで決まる装備は、`a, b` を `rf.turn` だけ回してから渡します (戦士の `shieldGeometry`)。重なり順の `bodyLayerKey` は上半身の座標を受け取り、内部でひねりを戻すので、そのまま渡せます。

### 2.5 奥側の武器が頭に隠れる

- **症状**: 右向きの戦士で、奥側 (左手) の剣が兜と羽飾りの裏に隠れ、振りかぶりが見えない。待機では盾の縁から剣身だけが生えて見えた。
- **直し方**:
  - 振りかぶりは、背中側の兜より外に剣身が出る位置を通します (戦士: 手を背中の後ろ、剣を後ろ上へ)。
  - 頭の裏を通る1コマ程度の通過は許容します。
  - 頭が大きく横に広いキャラクター (王・魔王) では、肩の高さでも剣が頭や髪に隠れます。顎より下の高さへ引き、刃が背中側のマントの上に出るようにします (王・魔王の左向き)。
  - 構えでは、握りを盾や体の前に出して籠手を見せます。

### 2.6 手前側の武器が顔に重なる

- **症状**: 左向きの戦士で、手前側 (左手) の剣が兜や盾に重なる。手前を向くと短く見え、鋼の剣と鋼の兜は見分けにくい。
- **直し方**:
  - 重なり順は正しく手前になっているかを確かめます (描画順の配列で、剣が兜より後か)。
  - 構えは、剣身が盾の上端より上に出るように握りの位置を選びます (戦士の左向きは握りを中心寄り・少し高く)。
  - 頭の横を通る手前側の剣は兜に重なって見えますが、奥行きが頭の横なら物理的には正しい位置です。

### 2.7 武器が体を通り抜ける

- **症状**: 振りかぶりで手が胸の中を通り、刃が頭を横切る (戦士の左向きで指摘を受けた)。右向きでも同じことが起きていたが、兜の裏で見えなかった。
- **原因**: 手を胸の前から背中の後ろへ**まっすぐ**動かした。
- **知っておくこと**: ちびキャラの腕は兜の上まで届きません。戦士は肩の高さ 44、腕の長さ約24 なので、手は高さ約68 (目の高さ) までです。兜の頂点は約92 です。
- **直し方**: 武器は体の外側を回します。
  - 剣を立てるときは、手を肩の外側 (`b ≥ 20`) に出し、刃を頭の横に通す。
  - 背中側に引くときは、手を胴の後ろ (`a ≤ −14`) に置く。
  - 前から後ろへ、胴の中をまっすぐ横切る経路を作らない。

戦士の横向きの攻撃の軌道 (上半身の座標。`[手 a, b, z, 刃の向き]`):

| 位相 | 姿勢 | 手 | 刃の向き |
|---|---|---|---|
| 0 | 構え | 向きごとの `SIDE_SWORD_READY` | 前上 |
| 0.1 | 手を肩の外へ、剣を立てる | [3, 22, 50] | ほぼ真上 |
| 0.2 | 後ろへ引き始め | [−10, 18, 50] | 後ろ上 |
| 0.3〜0.45 | 背中側で構える | [−18, 10, 47] → [−17, 11, 49] | 後ろ上 |
| 0.49 | 再び肩の上 | [2, 21, 56] | 前上 |
| 0.55 | 振り下ろし | [18, 16, 29] | 前下 |
| 0.62〜0.72 | 振り抜き (剣先は床の少し上) | [17, 15, 29] → [15, 16, 30] | 前下 |
| 1 | 構えに戻る | 構え | 前上 |

### 2.8 剣先が床に潜る

- **症状**: 振り抜きで剣先が床より下に出る (戦士では最大で床の下3)。
- **直し方**: 振り抜きの刃の向きを浅くし、剣先の高さ `z` を 0 以上にします。

### 2.9 構えを左右でそろえる

- 右向き・左向きで同じ構えに見えるようにします。戦士は「肘を曲げて握りを体の前に置き、剣先を斜め前上に向ける」構えで統一しました。
- 待機の呼吸・歩行の揺れは、構えの上に差分として加えます。
- 攻撃の最初と最後 (位相 0 と 1) を構えと同じ値にし、待機との切り替えで剣が跳ばないようにします。
- 2.6 のとおり手前・奥で見え方が変わるので、構えの数値は向きごとに決めます。

## 3. 武器の軌道を設計する手順

1. **構えを決める**: 向きごとに手の位置と刃の向きを決め、両方の向きで同じ構えに見えるか確かめる。
2. **要所の姿勢を上半身の座標で書く**: 構え → 振りかぶり → 溜め → 振り下ろし → 振り抜き → 構え。ループの始めと終わりは構えにそろえる。
3. **腕の届く範囲に収める**: 肩から手までの距離を、上腕 + 前腕の長さ以下にする (戦士は肩 `[0, ±16, 44]`、腕の長さ 11.8 + 12.3)。
4. **体の外側を回す**: 胴 (楕円柱) と頭 (球) を避ける経路にする。刃を立てる瞬間は手を肩の外側へ出す。
5. **見え方を見積もる**: 1章の式で、奥側の武器が頭に隠れる区間・手前側の武器が顔に重なる区間を確かめる。
6. **自動検査を通す**: 手・刃が胴や頭に入らないか、刃先が床に潜らないかを全位相で調べる。
7. **全コマを見る**: 左右の全コマを並べて、つながり・見え方・左右の対応を確認する。

戦士で使った体の大きさ (上半身の座標、倍率1):

| 部位 | 形 | 寸法 |
|---|---|---|
| 胴 (胸当て) | 楕円柱 | 前後 ±10、左右 ±17、高さ 14〜48 |
| 頭 (兜) | 球 | 中心 [1.5, 0, 66]、半径 18 (兜の絵は 0.9 倍) |
| 床 | 平面 | 高さ 0 |

これは戦士固有の値です。体格の違うキャラクターでは測り直してください。

## 5. 他のキャラクターに当てはめるとき

全11体をこのガイドで点検し、次のように直しました。数値は各キャラクターの固有値で、体格や武器の違うキャラクターにそのまま使わないでください。

| キャラクター | 見つかった問題 | 直し方 |
|---|---|---|
| 灰燼の衛士 | 体が薄い、振りかぶりが見えない、構えが左右で違う、武器が体を通る | 本ガイドの実例 (2.1〜2.9) |
| 剣士 | 構えが左右で違う、左向きの振りかぶりが頭に隠れる、振り下ろしが短い、左向きで手前の盾が体の後ろに描かれる、盾の面が胸とずれる | 胸の前の構え `SIDE_READY`、左向きの引き構え、攻撃中の `travelDir`、左向きは手前の盾を体の前に、盾の面を `chestToLegs` で回す |
| 骸骨の番兵 | 体が薄い (独自フレームでひねりが効かない)、構えが左右で違う、左向きの振りかぶりが隠れる | 上半身用の投影 `JU` / `WU`、構え `SIDE_READY`、左向きの引き構え、`travelDir` (右向きは頭上で停止) |
| 王・魔王 | 左向きの振りかぶりが頭に隠れる、振り下ろしが短い | 左向きは顎より下へ引く、`travelDir` |
| ゴブリン | 振り下ろしが脚の前で短い | `travelDir`。構えは左右で傾きが違う (右向きは前傾、左向きは肩越し) が、左向きは手前の手で頭が大きく、前傾にすると棍棒が顔を横切るため残した |
| 魔法使い | 左向きの詠唱で杖が手前を向いて短い、左向きで手前の杖が帽子のつばの裏に描かれる | 左向きの詠唱中だけ `travelDir`、左向きは杖を帽子のつばより手前に描く |
| 暗黒魔法使い | 左向きの詠唱で杖の頭がフードの裏に隠れる | 左向きは杖と握りをフードより手前に描く、詠唱中の `travelDir`。手前の杖はフードに重なって見える (2.6) |
| 弓使い・骸骨弓兵 | 横向きで弓が手から離れる (左向きの待機では脚の裏に隠れた)、左向きで手前の弓の腕の前につがえた矢が描かれる | 弓の投影 `UG`・矢の発射位置・弓の傾きの選択に `chestToLegs`、左向きはつがえた矢と引き手を弓の腕より奥に描く |
| スライム | なし | — |

- 弓使い・骸骨弓兵の矢は、横スクロールの画面で確認しました。放つ瞬間、飛ぶ矢は引き手の位置 (矢筈) から始まり、つがえた矢と同じ高さで画面の水平に飛びます。つがえた矢は進行方向 (真横から手前へ 25°) に沿ってわずかに下を向くので、放った瞬間に矢の傾きが水平へ変わります。通常の大きさでは目立ちませんが、気になる場合は飛び始めだけ傾きを残す方法があります。

## 6. 全キャラクターを点検する進め方と落とし穴

共通リグを変えたとき、ガイドに項目を足したとき、新しいキャラクターをまとめて見直すときの手順です。全11体の点検 (5章) で実際に使い、つまずいた点も書き残します。

### 手順

1. **自動検査を先に走らせる**: `node --test tests/node/side-clearance.test.mjs`。体を通り抜ける・床に潜る問題は、小さな画像では見落としやすい。武器を持つキャラクターが `ARMED` に入っているかも確かめる。
2. **待機を左右で並べる**: `side-overview.html?cells=R:idle:0,L:idle:0&s=0.98&ids=…` で4体ずつ。構えが左右で同じに見えるか、装備が手にあるか、隠れている装備がないかを見る。
3. **攻撃を左右で並べる**: `side-sheet.html?id=…&act=attack&s=0.7&cols=3&n=9&dirs=R,L` で等間隔9コマ。奥側の振りかぶりが消えていないか、振り下ろしが前へ届いているか、手前の武器が顔を横切っていないか。気になる位相は `p=` と大きい `s` で拡大する。
4. **向きで分けた補正を洗い出す**: `grep -nE "(direction|dirKey)==='(R|L)'" src/characters characters` で一覧にし、奥・手前の対応 (1章) に合っているかを見る。
5. **問題を表にしてから直す**: キャラクター・向き・位相・ガイドの項目番号で整理し、共通の原因 (2.3 の振り下ろしの短さなど) は共通リグの道具 (`travelDir`・`chestToLegs`) で、固有の問題はキャラクター側で直す。
6. **直したら全員で確かめ直す**: `npm test` (直していないキャラクターの絵の指紋が変わらないこと)・`check.html` (描画範囲)・2〜3の並べ比べ。直したキャラクターの指紋は `npm run drawings:update` で作り直す。

### 落とし穴

- **見えない原因は数値で確かめる**: 装備が消えたら、手と武器の先端の画面座標、描画順 (`draw` が返す `order`) を計算して、「描画順で裏に回った」「頭や髪の絵に隠れた」「体を通っている」のどれかを切り分ける。王の左向きは、刃先が頭の外へ出ていたが、横に広い髪と耳の絵に隠れていた。
- **自動検査の体の大きさは、そのキャラクターの描画順の判定に合わせる**: 骸骨の頭蓋骨は絵が大きく、球の半径を 20 にすると、刃が頭蓋骨の裏へ回る位相を検出できなかった。骸骨自身の描画順の判定と同じ半径 24 にした。直したあとは、直す前の悪い姿勢がその検査で検出されることも確かめる。
- **補正の向きを確かめる**: `travelDir` は武器を体の外側へ開く向きにも内側へ寄せる向きにも回す (2.3 の注意)。回した直後に自動検査を走らせる。
- **共通リグの変更は独自の投影に波及する**: 上半身のひねりを入れたとき、`U` を使わず独自の投影で弓を描いていた弓使い・骸骨弓兵だけ、弓が手から離れた。共通リグを変えたら、`bodyToWorld` や独自の投影を使っている箇所を `grep -n "bodyToWorld" src/characters characters` で洗い出す。
- **判断で残したものは理由と一緒に記録する**: ゴブリンの構えのように、ガイドの原則と体格の制約がぶつかる場合は、残した理由を5章の表に書き、報告でも伝える。
