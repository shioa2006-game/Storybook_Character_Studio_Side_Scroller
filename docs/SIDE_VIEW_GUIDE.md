# 横向きキャラクター制作ガイド

横スクロール用の右向き (R)・左向き (L) でキャラクターを仕上げるためのコツ・落とし穴・確認方法です。灰燼の衛士 ([warrior](../characters/warrior/character.js)) を横向きに調整したときに確かめた内容をまとめています。

描き方の基本 (座標系・顔や髪・装備・描画順・コマ割り) は [CHARACTER_GUIDE.md](CHARACTER_GUIDE.md)、登録と確認範囲は [STUDIO_GUIDE.md](STUDIO_GUIDE.md)、横スクロール化の計画は [SIDE_SCROLLER_PLAN.md](SIDE_SCROLLER_PLAN.md) を参照してください。

## 1. 横向きの見え方の仕組み

### 2つの角度

| 部位 | 座標 | 見る角度 | 理由 |
|---|---|---|---|
| 脚・足運び | `W`・`footProj` | 真横から手前へ `SIDE_VIEW_ANGLE` = 25° | 足を画面の横方向に動かし、地面の上で滑らせない |
| 上半身・腕・装備 | `U` / `UY` | さらに `SIDE_CHEST_TURN` = 20° カメラ側へひねって 45° | 胴を4方向の絵と同じ幅で見せる |
| 頭 | 2Dの絵 (`rf.front` = 正面系、`rf.sx` で反転) | 向きによらない | 正面系・背面系の2種類しかない |

ひねりの量は `rf.turn` で、右向きは正、左向きは負、4方向では 0 です。真横 (0°) にすると `rf.front` が偽になり、頭が後頭部の絵になります。

胴・ベルト・腰当てなどは、前後の厚みのない「板」として描いています。板の見える幅は角度で変わります。

| 角度 | 板の見える幅 |
|---|---|
| 4方向 (45°) | 約71% |
| 横向きの脚の角度 (25°) | 約42% (細い板に見える) |
| 上半身のひねり後 (45°) | 約71% |

### 左右反転しない: 奥側の手と手前側の手

持ち手を保つため、左右反転 (`mirror`) は使わず投影で描きます。そのため、同じ手でも向きによって奥側・手前側が入れ替わります。

| 向き | 左手 (`b > 0`) | 右手 (`b < 0`) |
|---|---|---|
| 右向き R | 奥側 | 手前側 |
| 左向き L | 手前側 | 奥側 |

上半身の座標 (a = 前、b = 左) が画面のどこに出るかの目安は、次のとおりです (ひねり後の 45°、`yaw` = 0 のとき)。

- 画面の横: `x ≒ s × a × 0.71 + b × 0.71` (右向き s = +1、左向き s = −1)
- 画面の縦: `y ≒ −z`

体の左 (`b`) は、右向き・左向きのどちらでも画面の右側へずれます。そのため同じ座標でも、右向きでは前寄り、左向きでは後ろ寄りに見えます。**左右で同じ見え方にしたい部分は、向きごとに数値を調整する必要があります** (戦士の構え `SIDE_SWORD_READY`)。

### 横向き専用の処理の書き方

- 横向きだけの補正は `if(direction==='R'||direction==='L') { … }`・`if(direction==='R') { … }`・`if(rf.turn) { … }` のブロックに書きます。定数は `SIDE_` で始めます。
- こうしておくと、4方向 (8×8ダンジョン用) の絵が変わっていないことをテストで確かめられます (`tests/node/tools.test.mjs` の戦士の比較は、このブロックと定数を除いて元の原本と照合します)。

## 2. よくある問題と直し方

### 2.1 体が薄く見える

- **症状**: 胴が細い板になり、大きな頭の下で「ぺらぺら」に見える。
- **原因**: 脚の角度 (25°) のまま胴を描いている。
- **直し方**: 共通リグが上半身を自動でひねります。上半身を `U` / `UY` で描けば効きます。`W` で上半身を描くキャラクター (骸骨の番兵) には効かないので、横向きの調整時に `U` へ移します。

### 2.2 攻撃中のひねりでさらに薄くなる

- **症状**: 振りかぶり・振り下ろしの一方で、胴が真横へ回って細くなる。
- **原因**: 攻撃のひねり (`yaw`) が、カメラから離れる向きに回る区間がある (戦士では左向きの振り下ろしと右向きの振りかぶり)。
- **直し方**: 横向きでは、カメラから離れる側のひねりだけを弱めます。戦士は `SIDE_TWIST_AWAY = 0.3` 倍。右向きは `yaw < 0`、左向きは `yaw > 0` が離れる側です。

### 2.3 振り下ろしが短く見える

- **症状**: 横へ振ったはずの剣が手前を向き、横方向の届きが短い。剣の軌跡も盾に隠れる。
- **原因**: 胸がカメラを向いた分、胸の前へ振る武器も手前を向く。
- **直し方**: 振り下ろしの間だけ、武器の**向き**を `rf.turn + rf.yaw` だけ戻して進行方向へ向けます。手の位置は動かさないので、腕が伸びすぎません (戦士の攻撃の `back`)。

### 2.4 装備の面の向きがずれる

- **症状**: 盾の面が胸と違う方向を向く。
- **原因**: `bodyToWorld(rf.dir, a, b)` は脚の向きで計算する。
- **直し方**: 上半身の向きで決まる装備は、`a, b` を `rf.turn` だけ回してから渡します (戦士の `shieldGeometry`)。重なり順の `bodyLayerKey` は上半身の座標を受け取り、内部でひねりを戻すので、そのまま渡せます。

### 2.5 奥側の武器が頭に隠れる

- **症状**: 右向きの戦士で、奥側 (左手) の剣が兜と羽飾りの裏に隠れ、振りかぶりが見えない。待機では盾の縁から剣身だけが生えて見えた。
- **直し方**:
  - 振りかぶりは、背中側の兜より外に剣身が出る位置を通します (戦士: 手を背中の後ろ、剣を後ろ上へ)。
  - 頭の裏を通る1コマ程度の通過は許容します。
  - 構えでは、握りを盾や体の前に出して籠手を見せます。

### 2.6 手前側の武器が顔に重なる

- **症状**: 左向きの戦士で、手前側 (左手) の剣が兜や盾に重なる。手前を向くと短く見え、鋼の剣と鋼の兜は見分けにくい。
- **直し方**:
  - 重なり順は正しく手前になっているかを確かめます (描画順の配列で、剣が兜より後か)。
  - 構えは、剣身が盾の上端より上に出るように握りの位置を選びます (戦士の左向きは握りを中心寄り・少し高く)。
  - 頭の横を通る手前側の剣は兜に重なって見えますが、奥行きが頭の横なら物理的には正しい位置です。

### 2.7 武器が体を通り抜ける

- **症状**: 振りかぶりで手が胸の中を通り、刃が頭を横切る (戦士の左向きで指摘を受けた)。右向きでも同じことが起きていたが、兜の裏で見えなかった。
- **原因**: 手を胸の前から背中の後ろへ**まっすぐ**動かした。
- **知っておくこと**: ちびキャラの腕は兜の上まで届きません。戦士は肩の高さ 44、腕の長さ約24 なので、手は高さ約68 (目の高さ) までです。兜の頂点は約92 です。
- **直し方**: 武器は体の外側を回します。
  - 剣を立てるときは、手を肩の外側 (`b ≥ 20`) に出し、刃を頭の横に通す。
  - 背中側に引くときは、手を胴の後ろ (`a ≤ −14`) に置く。
  - 前から後ろへ、胴の中をまっすぐ横切る経路を作らない。

戦士の横向きの攻撃の軌道 (上半身の座標。`[手 a, b, z, 刃の向き]`):

| 位相 | 姿勢 | 手 | 刃の向き |
|---|---|---|---|
| 0 | 構え | 向きごとの `SIDE_SWORD_READY` | 前上 |
| 0.1 | 手を肩の外へ、剣を立てる | [3, 22, 50] | ほぼ真上 |
| 0.2 | 後ろへ引き始め | [−10, 18, 50] | 後ろ上 |
| 0.3〜0.45 | 背中側で構える | [−18, 10, 47] → [−17, 11, 49] | 後ろ上 |
| 0.49 | 再び肩の上 | [2, 21, 56] | 前上 |
| 0.55 | 振り下ろし | [18, 16, 29] | 前下 |
| 0.62〜0.72 | 振り抜き (剣先は床の少し上) | [17, 15, 29] → [15, 16, 30] | 前下 |
| 1 | 構えに戻る | 構え | 前上 |

### 2.8 剣先が床に潜る

- **症状**: 振り抜きで剣先が床より下に出る (戦士では最大で床の下3)。
- **直し方**: 振り抜きの刃の向きを浅くし、剣先の高さ `z` を 0 以上にします。4方向の絵では待機中も約2潜っていますが、元の絵として変えていません。床の検査は横向きだけに適用しています。

### 2.9 構えを左右でそろえる

- 右向き・左向きで同じ構えに見えるようにします。戦士は「肘を曲げて握りを体の前に置き、剣先を斜め前上に向ける」構えで統一しました。
- 待機の呼吸・歩行の揺れは、構えの上に差分として加えます。
- 攻撃の最初と最後 (位相 0 と 1) を構えと同じ値にし、待機との切り替えで剣が跳ばないようにします。
- 2.6 のとおり手前・奥で見え方が変わるので、構えの数値は向きごとに決めます。

## 3. 武器の軌道を設計する手順

1. **構えを決める**: 向きごとに手の位置と刃の向きを決め、両方の向きで同じ構えに見えるか確かめる。
2. **要所の姿勢を上半身の座標で書く**: 構え → 振りかぶり → 溜め → 振り下ろし → 振り抜き → 構え。ループの始めと終わりは構えにそろえる。
3. **腕の届く範囲に収める**: 肩から手までの距離を、上腕 + 前腕の長さ以下にする (戦士は肩 `[0, ±16, 44]`、腕の長さ 11.8 + 12.3)。
4. **体の外側を回す**: 胴 (楕円柱) と頭 (球) を避ける経路にする。刃を立てる瞬間は手を肩の外側へ出す。
5. **見え方を見積もる**: 1章の式で、奥側の武器が頭に隠れる区間・手前側の武器が顔に重なる区間を確かめる。
6. **自動検査を通す**: 手・刃が胴や頭に入らないか、刃先が床に潜らないかを全位相で調べる。
7. **全コマを見る**: 左右の全コマを並べて、つながり・見え方・左右の対応を確認する。

戦士で使った体の大きさ (上半身の座標、倍率1):

| 部位 | 形 | 寸法 |
|---|---|---|
| 胴 (胸当て) | 楕円柱 | 前後 ±10、左右 ±17、高さ 14〜48 |
| 頭 (兜) | 球 | 中心 [1.5, 0, 66]、半径 18 (兜の絵は 0.9 倍) |
| 床 | 平面 | 高さ 0 |

これは戦士固有の値です。体格の違うキャラクターでは測り直してください。

## 4. 確認方法とチェックリスト

| 道具 | 使い方 |
|---|---|
| Studio の詳細画面 | 向き「右向き R / 左向き L」、位相スライダー、スロー再生、「左右・全動作を見る」、通常ゲームサイズ、Live / Cached |
| [side-sheet.html](../tests/browser/side-sheet.html) | 1体の全コマを格子に並べる。例: `?id=warrior&act=attack&dirs=R,L`。`p` で位相を指定、`turns=0,20` で上半身のひねりの有無を比較、`dirs` に SE などの4方向も指定可 |
| [side-overview.html](../tests/browser/side-overview.html) | 全キャラクターの左右の待機と攻撃を一覧にする。共通リグを変えたときの影響確認に使う |
| [check.html](../tests/browser/check.html) | 全キャラクター・左右・全動作の描画範囲 (`frameBox`) と Live / Cached の確認 |
| `tests/node/warrior-side.test.mjs` | 戦士の横向きの全動作を401段階で調べ、手・刃が胴や頭に入ったり、刃先が床に潜ったりしたら失敗する。わざと貫く姿勢で検出できることも確かめる |
| `npm test` | 上記を含む全テスト。4方向の戦士の絵が変わっていないかも確認する |

ページはサーバー経由で開きます (`start-studio.bat` または `npm start` で表示された URL の後ろに `tests/browser/side-sheet.html?…` を付ける)。

**チェックリスト**

- [ ] 待機・歩行・攻撃 × 右・左の全コマを並べて見た
- [ ] 攻撃中も含めて、胴が薄く見えない
- [ ] 右向きと左向きで、同じ構え・同じ流れの動きに見える
- [ ] 奥側の武器が見えない区間は、頭の裏を通る1コマ程度
- [ ] 手前側の武器が顔に重なる区間が読める (描画順が手前か)
- [ ] 手・刃が胴や頭を通り抜けず、刃先が床より上にある (自動検査)
- [ ] 描画範囲からはみ出さない (`check.html`)
- [ ] 4方向の絵が変わっていない (`npm test`)
- [ ] 通常ゲームサイズでも動きが読める

## 5. 他のキャラクターに当てはめるとき

- 上半身のひねりは、上半身を `U` / `UY` で描くキャラクターすべてに自動で効きます。全11体で描画範囲の検査は通っていますが、構え・攻撃の見え方の調整は戦士だけ済んでいます。
- 骸骨の番兵は上半身を `W` で描いているため、ひねりが効かず細いままです。横向きを調整するときに `U` へ移します。
- 衛士の数値 (`SIDE_SWORD_READY`・攻撃の軌道・体の大きさ) は固有値です。体格や武器の違うキャラクターにそのまま使わないでください。
- 武器を持つキャラクターは、`tests/node/warrior-side.test.mjs` を複製し、体の大きさ・武器の長さ・持ち手を合わせて自動検査を作ります。
- 弓使い・骸骨弓兵の矢の発射位置 (`projectile.origin`) は脚の向きで計算しています。上半身のひねりと合っているかは、横スクロールの画面で矢を飛ばすときに確認します (未確認)。
